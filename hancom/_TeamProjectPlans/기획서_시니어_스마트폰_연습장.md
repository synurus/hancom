## 2. 배경 및 문제 정의

은퇴한 50~60대는 스마트폰을 손에 쥐고 있지만, 정작 자녀·손주와 소통하거나 일상을 편리하게 해주는 앱 앞에서는 막막해합니다. 사진을 보내고 싶은데 어디를 눌러야 할지 몰라 포기하고, 송금이나 배달 주문은 "잘못 누르면 큰일 난다"는 두려움 때문에 아예 시도하지 못합니다.

문제의 핵심은 **정보가 없어서가 아니라 "안전하게 연습할 곳이 없어서"**입니다. 실제 앱에서 이것저것 눌러보는 건 진짜로 돈이 나가거나 엉뚱한 메시지가 전송될 수 있어 무섭습니다. 영상 강의는 보는 것과 직접 해보는 것의 간극이 크고, 오프라인 교육은 시간·장소의 제약이 있습니다.

**"실수해도 아무 일도 일어나지 않는, 진짜 같은 연습 공간"**이 있다면 어르신은 두려움 없이 반복 학습할 수 있습니다. 이 프로젝트는 바로 그 공간을 만듭니다.

## 3. 타겟 사용자 페르소나

**김영자 (62세, 은퇴 후 3년차)**
- 스마트폰으로 전화·문자·유튜브 시청은 하지만, 카톡으로 손주 사진을 받기만 하고 보내지는 못한다.
- 배달앱을 깔았지만 결제 단계에서 "잘못 누를까 봐" 매번 포기하고 전화 주문을 한다.
- 자녀에게 물어보기는 미안하고, 같은 걸 세 번 물어보면 눈치가 보인다.
- **니즈:** 혼자서, 천천히, 틀려도 창피하지 않게 연습하고 싶다.

**핵심 페인포인트**
1. 실제 앱은 실수하면 진짜로 문제가 생겨 무섭다.
2. 자녀에게 반복해서 묻기 미안하다.
3. 영상은 봐도 막상 내 손으로 하면 안 된다.
4. 글씨가 작고 화면이 복잡해 눈과 손이 따라가기 어렵다.

## 4. 경쟁 서비스 조사 및 차별점

### 4.1 조사 결과

**① 시니어 디지털 교육 "콘텐츠"는 이미 포화**
경기도 GSEEK 스마트폰 활용백서, 서울시 50+·디지털 배움터, 카카오임팩트 시니어 디지털 스쿨 등 영상 강의·오프라인 수업·블로그 가이드가 넘쳐납니다. 그러나 대부분 **정적 콘텐츠(영상/글)이거나 사람이 직접 가르치는 방식**입니다.

**② "인터랙티브 모의 연습" 포맷은 정부가 이미 운영 중**
정부 디지털 배움터에 **시뮬레이터**가 존재합니다. 실제 앱 화면을 흉내낸 위에서 사용자가 직접 눌러가며 미션을 수행하는 방식(배우기 → 연습 → 자유학습)입니다. 해외에도 호주 정부의 Be Connected가 인터랙티브 실습 모듈을 제공합니다. 즉, **"모의 연습 시뮬레이터"라는 포맷 자체는 새롭지 않습니다.**

**③ 그러나 커버리지에 명확한 빈틈이 있음**
정부 시뮬레이터가 다루는 것은 **키오스크·공공 서비스 중심**입니다(식당·병원 키오스크, 쇼핑·택시·버스·KTX 앱, 무인민원발급기 등). 정작 어르신이 가장 원하고 가장 두려워하는 **일상 소통·생활 앱 — 카카오톡(사진·이모티콘 전송, 송금, 영상통화), 배달, 중고거래 — 은 인터랙티브 연습에서 빠져 있습니다.** Be Connected는 메신저를 다루지만 영어권·해외 앱이라 국내 어르신에게 맞지 않습니다.

### 4.2 차별점 및 포지셔닝

> **"공공 키오스크는 정부가, 일상 소통 앱은 우리가."**
> 어르신이 진짜로 무서워하는 '카톡·일상 앱'을 안전하게 연습시킨다.

| 구분 | 기존 서비스 | 차근차근 |
| --- | --- | --- |
| 학습 방식 | 영상·글·오프라인 강의 | 직접 눌러보는 인터랙티브 연습 |
| 다루는 앱 | 공공 키오스크·교통·쇼핑 | **일상 소통·생활 앱(메신저 중심)** |
| 대상 정서 | "기능을 안내" | **"실수해도 괜찮다"는 안전감** |
| 접근성 | 일반 수준 | **시니어 특화(큰 글씨·고대비·음성 안내)** |

포트폴리오 관점에서 이 주제의 진짜 가치는 **시그니처 인터랙션의 기술 난이도**에 있습니다. "진짜처럼 생긴 가짜 앱 UI를 만들고, 그 위에서 가이드 연습을 굴리는 엔진"은 프론트엔드 실력을 정면으로 증명합니다. 정부 서비스가 존재한다는 사실은 오히려 "이것이 가치 있고 기술적으로 어려운 일"이라는 검증입니다.

## 5. 핵심 기능

### 5.1 시그니처 인터랙션 — 핫스팟 가이드 연습 엔진 ★

프로젝트의 심장입니다.

- 진짜 같은 가짜 앱 화면 위에 **"여기를 눌러보세요" 하이라이트**를 표시
- 맞는 곳을 누르면 → 다음 단계로 애니메이션 전환
- 엉뚱한 곳을 누르면 → 부드러운 힌트 제공(질책 없음)
- 여러 단계를 묶어 "친구에게 사진 보내기" 같은 하나의 미션을 완성
- 내부적으로 **가이드 상태머신**이 현재 단계·성공/실패·힌트 노출을 관리

실제 앱 UI 재현 + 단계 흐름 관리 + 제스처(탭) 감지가 모두 들어가므로, 팀 리소스를 이곳에 집중합니다.

### 5.2 핵심 기능 3종

**핵심 1 — 모의 앱 화면 + 핫스팟 가이드 연습**
가짜 메신저 화면에서 단계별 가이드 연습을 진행합니다. 정부 사례처럼 **배우기 → 따라하기 → 혼자하기** 3단계 구성으로, 학습 난이도를 점진적으로 높입니다.

**핵심 2 — 미션형 커리큘럼**
앱별 실생활 미션 목록을 제공합니다(예: "사진 보내기", "이모티콘 쓰기", "송금하기", "영상통화 걸기"). 미션 콘텐츠를 데이터 구조로 분리해 새 미션 추가가 쉽도록 설계합니다.

**핵심 3 — 진행·성취 트래킹**
진도율·배지·"이제 혼자 할 수 있어요" 체크 등으로 성취감을 시각화합니다. 성취감은 시니어 학습 지속의 핵심 요소이므로 UX적으로도 중요합니다.

### 5.3 확장 기능 (여유 시)

- 자주 틀린 단계만 모아 복습하는 **오답 복습**
- 자녀가 "이것부터 배우세요"라고 추천하는 **가족 맞춤 미션**

## 9. 확장성 (Scalability)

현재 MVP는 **메신저 앱 1개(카톡류) + 미션 3~5개**에 집중하지만, 구조적으로는 아래와 같이 확장할 수 있도록 설계합니다.

### 9.1 앱·미션 확장 (콘텐츠 구조 분리)
가이드 엔진과 콘텐츠(앱 화면·미션 시나리오)를 분리해두면, **새로운 앱과 미션을 데이터 추가만으로 확장**할 수 있습니다. 배달·중고거래·지도·금융 앱 등을 순차적으로 늘려갈 수 있습니다.

### 9.2 인기 앱 자동 반영 (앱스토어 순위 연동) ★
**어떤 앱을 다음에 추가할지**를 팀의 감이 아니라 데이터로 정하기 위해, **구글 플레이스토어·애플 앱스토어의 인기 순위 데이터를 받아와** 타겟 연령층(50~60대)이 많이 사용하는 앱을 파악하고 커리큘럼에 우선 반영하는 확장을 제안합니다.

- 플레이스토어·앱스토어의 **인기/무료 앱 랭킹**을 주기적으로 수집
- 그중 **시니어 사용 비중이 높은 생활·소통 앱**을 선별해 "다음에 배울 앱" 후보로 큐잉
- 트렌드 변화(신규 인기 앱 등장)에 맞춰 **연습 콘텐츠를 지속적으로 갱신**
- 이를 통해 "지금 어르신들이 실제로 가장 많이 쓰는 앱"을 놓치지 않고 따라감

> 이 확장은 "우리 서비스가 한 번 만들고 끝나는 콘텐츠가 아니라, 시장 변화에 맞춰 살아 움직이는 학습 플랫폼"임을 보여주는 포인트입니다. (구현 시 각 스토어의 데이터 제공 정책·이용약관을 확인하고, 공식 API 또는 공개 랭킹 페이지를 활용합니다.)

### 9.3 개인화·가족 연동
학습 이력을 기반으로 **자주 틀리는 단계 맞춤 복습**, 자녀가 부모님께 미션을 추천·공유하는 **가족 연동** 기능으로 확장할 수 있습니다.

## 10. 리스크 및 대응

| 리스크 | 대응 |
| --- | --- |
| **정부 시뮬레이터 존재** | 커버리지를 "일상 소통 앱"으로 차별화. 발표에서 "공공 키오스크는 정부, 일상 앱은 우리"로 명확히 포지셔닝 |
| **저작권·상표 문제** | 실제 카카오톡 로고·브랜딩을 그대로 복제하지 않고, **"카톡과 유사한 가상의 메신저 앱"으로 각색**(이름·로고·색 변경). 법적으로 안전하고 디자인 시스템을 직접 설계했다는 어필도 됨 |
| **범위 초과(Scope creep)** | 4주 내 여러 앱 재현은 불가능. **메신저 앱 1개를 완성도 높게** + 미션 3~5개로 고정. 앱 확장은 v2 |
| **시니어 접근성 미흡** | 큰 글씨·고대비·음성 안내·느린 애니메이션을 **선택이 아닌 필수**로 설계. WCAG 기준 준수를 포트폴리오 서사로 활용 |

## 11. 기대 효과 및 비전

- **사용자 가치:** 어르신이 두려움 없이 반복 연습해 실제 앱을 스스로 쓸 수 있게 되고, 자녀와의 소통이 늘어납니다.
- **사회적 가치:** 디지털 소외 해소에 기여합니다.
- **포트폴리오 가치:** 가짜 앱 UI 재현 + 가이드 상태머신 + 시니어 접근성이라는, 프론트엔드 실력을 정면으로 증명하는 결과물을 남깁니다.
