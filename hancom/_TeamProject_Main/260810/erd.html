PK = 기본키(고유 식별자) · FK = 외래키(다른 테이블 참조) · null = 값이 없어도 되는 컬럼
┃──○ 표기는 1:N 관계 — 왼쪽 테이블 1개에 오른쪽 테이블 row가 여러 개 붙을 수 있다는 뜻 (점선은 아직 확정되지 않은 제안 관계)
NEW 이번 리뷰에서 새로 추가된 컬럼/테이블 · 변경 기존 컬럼을 대체/수정한 부분
파란 영역 — 콘텐츠 데이터(변경 없음) · 주황 영역 — 게임 기록 데이터(round·ended_at 추가) · 초록 헤더 — 이번에 신설된 테이블(game_votes, players, survey_questions, survey_reasons, survey_response_reasons)
survey_responses의 reason_ids 배열은 survey_response_reasons 중간 테이블로 정규화되어 제거됨 — 배열과 달리 FK 무결성이 실제로 보장됨
FK* = (game_id, 라벨) 복합 FK로 players(game_id, player_label)를 참조 — 새 컬럼 추가 없이 기존 라벨 컬럼에 바로 건 제약. 텍스트 라벨 매칭에 실제 무결성을 보장함
