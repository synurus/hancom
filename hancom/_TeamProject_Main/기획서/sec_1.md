# 프로젝트 기획서

## "마음이음" — AI 기반 5060세대 정서 케어 & 맞춤 건강관리 서비스

---

## 1. 프로젝트 개요

| 항목 | 내용 |
|---|---|
| 프로젝트명 | 마음이음 (가칭) |
| 타겟 | 50~60대 / 은퇴 실버 세대 |
| 팀 규모 | 4인 |
| 개발 기간 | 1개월 |
| 한 줄 소개 | AI와의 대화로 시작해, 감정을 기록하고, 패턴을 발견하고, 맞춤 케어까지 이어지는 정서·건강 관리 서비스 |

---

## 2. 기획 배경 (문제 정의)

- 은퇴 후 하루 대화 상대가 없어지고, 사회적 고립감이 커짐
- 자녀와는 세대차이로 깊은 대화가 어려움
- 감정 상태를 스스로 인식하지 못하고 지나치는 경우가 많음 (무기력, 스트레스 누적 등)
- 건강기능식품/생활습관 정보가 넘쳐나지만 본인 상태에 맞는 정보를 찾기 어려움
- → **"마음을 나눌 상대"와 "내 상태에 맞는 관리법 추천"이 분리되어 있어 연결이 필요함**

---

## 3. 핵심 컨셉

기존에는 "정서 케어"와 "건강 관리"가 서로 다른 서비스였다면, 이 프로젝트는 **하나의 파이프라인**으로 연결합니다.

```
① 말벗 챗봇과 대화
        ↓
② 감정일기 자동 기록
        ↓
③ 감정 체크 (일별 점수/키워드화)
        ↓
④ 패턴 감지 (기간별 트렌드 분석)
        ↓
⑤ 관리 조언 (영양제 / 생활습관 / 운동 추천)
```

감정 상태를 근거로 맞춤 케어를 추천하기 때문에, "왜 이 영양제/운동을 추천하는가"에 대한 설득력 있는 이유가 생깁니다.

---

## 4. 핵심 기능 상세

### ① 말벗 챗봇
- 일상 대화 (날씨, 취미, 오늘 하루 어땠는지)
- 존댓말, 친근하되 예의 있는 말투
- 매일 정해진 시간에 먼저 안부 인사 (알림 UI)

### ② 감정일기 자동 기록
- 챗봇과 나눈 대화를 AI가 1인칭 일기 형식으로 자동 요약
- 사용자가 다시 읽거나 직접 수정 가능

### ③ 감정 체크
- 대화/일기에서 감정 키워드 추출 (외로움, 무기력, 짜증, 활력 등)
- 하루 단위 감정 점수화 (예: -5 ~ +5)

### ④ 패턴 감지
- 기간별(주간/월간) 감정 데이터 누적 → 반복·지속 패턴 탐지
- 트렌드 그래프 + 캘린더 히트맵으로 시각화
- 예: "최근 2주간 무기력함이 자주 느껴지셨네요"

### ⑤ 관리 조언 (영양제 / 생활습관 / 운동 추천)
- 감지된 감정 패턴에 맞춘 맞춤 조언 제공
- 예: "무기력함이 반복돼요 → 비타민D, 오메가3 같은 성분이 도움될 수 있어요 + 가벼운 걷기 운동 어떠세요?"
- 영양제는 성분 단위로 안내 (브랜드 추천 X)

> ⚠️ **원칙**: 모든 조언은 "진단"이 아닌 "정보 제공 + 인식 지원"으로 포지셔닝. "우울증 의심", "치료 필요" 같은 표현 금지 → "최근 기분이 가라앉는 날이 많았어요", "전문가와 이야기 나눠보는 것도 방법이에요" 등으로 순화.

## 5. AI 활용 지점 요약

| 단계 | AI 역할 | 입력 → 출력 |
|---|---|---|
| ① 챗봇 대화 | 대화 생성 | 사용자 발화 → 공감형 응답 |
| ② 일기 생성 | 텍스트 요약/재구성 | 대화 로그 → 1인칭 일기 텍스트 |
| ③ 감정 체크 | 구조화 데이터 추출 | 일기/대화 → JSON (감정 태그 + 점수) |
| ④ 패턴 감지 | 트렌드 분석 & 인사이트 생성 | 누적 감정 데이터 → 패턴 요약 텍스트 |
| ⑤ 관리 조언 | 맞춤 추천 생성 | 감정 패턴 → 영양제/습관/운동 추천 + 이유 설명 |

→ 하나의 서비스 안에서 AI가 **대화 생성 / 요약 / 데이터 구조화 / 트렌드 분석 / 추천 생성**까지 다섯 가지 방식으로 활용됨.

## 9. 4주 타임라인

**1주차 — 기획 & 설계**
- 페르소나 정의, 전체 유저 플로우 설계
- 팀원 2: 감정 분석 프롬프트 + 표현 톤 가이드 확정
- 팀원 3: 관리 조언 매핑표 작성 (감정 패턴 ↔ 추천 항목)
- 팀원 4: 디자인 시스템 초안

**2주차 — 핵심 기능 개발**
- 팀원 1: 채팅 UI + 일기 생성 연동
- 팀원 2: 감정 데이터 구조 설계 + 차트/히트맵
- 팀원 3: 추천 로직 + 카드 UI
- 팀원 4: 공통 컴포넌트, 온보딩

**3주차 — 통합 & 다듬기**
- 전체 파이프라인 연결 (①→②→③→④→⑤)
- 패턴 감지 → 추천 연동 테스트
- 접근성 점검

**4주차 — 테스트 & 발표 준비**
- 시나리오 기반 통합 테스트
- 데모 영상/PPT 제작

## 10. 프롬프트 설계 (단계별)

**① 대화 생성**
> "당신은 5060세대와 대화하는 친근한 말벗입니다. 존댓말을 사용하고 짧고 이해하기 쉽게 답하세요."

**② 일기 생성**
> "오늘 나눈 대화를 1인칭 일기 형식으로 요약해줘. 담백하고 본인 말투처럼."

**③ 감정 체크** — JSON만 반환
```json
{"date": "2026-07-27", "emotions": ["무기력", "외로움"], "score": -2}
```

**④ 패턴 감지**
> "최근 2주간의 감정 데이터를 분석해서 반복되는 패턴이 있는지 짧게 요약해줘. 진단 표현은 쓰지 말고 관찰된 사실 위주로."

**⑤ 관리 조언**
> "다음 감정 패턴에 맞는 영양소, 생활습관, 가벼운 운동을 성분/항목 단위로 추천하고 이유를 쉬운 말로 설명해줘. 브랜드명은 언급하지 마."

## 12. 기대 효과 및 차별점

- **연결된 파이프라인**: 대화 → 기록 → 분석 → 추천이 하나의 흐름으로 이어져, "왜 이 조언을 하는가"에 대한 근거가 명확함
- **AI 활용의 다양성**: 대화 생성부터 데이터 구조화, 트렌드 분석, 추천 생성까지 AI가 다각도로 쓰임
- **공감도 높은 문제 해결**: 정서적 고립과 건강 관리라는, 5060세대에게 실질적으로 와닿는 문제를 함께 해결
- **신중한 설계**: 민감한 주제를 다루면서도 표현과 포지셔닝을 신경 써 신뢰도와 안전성을 모두 확보
