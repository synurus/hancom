방 목록 화면 시안 — 아이디만 입력하고 방을 골라 들어가는 방식

지금은 아이디 + 방번호를 같이 입력해서 입장한다. 방번호를 몰라도 되도록, 아이디만 입력하면 지금 입장 가능한 방을 화면에서 직접 찾아 고르는 방식으로 바꾸는 안이다. 큰 방향이 두 가지로 갈린다 — 아이디 입력 후 다음 화면에서 목록을 보여줄지, 아니면 입력 화면 안에 목록을 같이 띄울지. 방향마다 각각 3개씩, 총 6개 시안을 아래에 그려뒀다. 모바일(390px) 기준으로 만들었고, 폭이 넓어질 때 레이아웃이 실제로 달라지는 안은 데스크톱 프레임도 같이 붙여뒀다.

옵션 A — 2단계(아이디 → 목록 화면)

입력 화면과 목록 화면이 분리된다. 목록에 쓸 공간이 넉넉해서 정렬·필터 같은 기능을 넣기 쉽지만, 탭이 한 번 더 늘어난다.

옵션 B — 1단계(입력 화면 안에 목록)

한 화면 안에서 끝난다. 화면 전환이 없는 대신, 좁은 모바일 폭 안에 입력폼과 목록을 같이 욱여넣어야 한다.

A1 · 단순 리스트 A2 · 카드 그리드 A3 · 필터·정렬 B1 · 좌우 분할 B2 · 드롭다운 선택 B3 · 상시 미니 목록
옵션 A · 1안

단순 리스트 — 탭하면 바로 입장

가장 적은 개념으로 끝난다. 아이디 입력 → 목록 화면에서 방을 탭하면 그대로 입장. 확인 절차가 없어 빠르지만, 잘못 탭했을 때 되돌릴 방법이 없다.
