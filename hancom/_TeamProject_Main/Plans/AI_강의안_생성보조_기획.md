# AI 강의안/수업자료 생성 보조 서비스 기획

## 프로젝트 개요

- **아이템**: 학교 교사·학원강사 대상 AI 강의안/수업자료 생성 보조 서비스
- **타겟**: 학교 교사, 학원강사
- **결제모델**: 무료~프리미엄까지 5단계 요금제(하단 "요금제" 참고), 자유 게시판(커뮤니티)은 광고 수익으로 별도 창출
- **팀 규모/기간**: 4인, 6주
- **성격**: 팀플 평가용 + 실서비스(창업) 겸함

## 핵심 원칙

AI는 강의안·수업자료의 **초안**만 생성한다. 최종 교육 내용, 수준 조정, 학생 맞춤화 판단은 항상 교사가 내린다. PT 서비스 기획 때와 같은 원칙 — AI가 전문가(트레이너/교사)의 판단 영역을 대신하지 않고, 반복적인 자료 작성 업무만 자동화한다.

이 원칙이 필요한 이유:
- 같은 주제라도 학급 수준, 학생 특성에 따라 강의 방식이 달라져야 하는데, AI는 이런 맥락을 알 수 없음
- 교사가 AI 초안을 그대로 쓰는 게 아니라 "빠르게 초안 잡고 다듬는" 도구로 포지셔닝해야 신뢰를 얻음

## 핵심 기능

| # | 기능 | 내용 |
|---|---|---|
| 1 | 강의안 초안 생성 | 주제·성취기준 입력 → AI가 강의안 초안(도입-전개-정리) 생성 |
| 2 | 활동지/수업자료 자동 생성 | 강의안 기반으로 학생용 활동지, 워크시트 자동 생성 |
| 3 | 평가문항 초안 생성 | 객관식·서술형 평가문항 초안 생성. 최종 검수는 교사가 수행 |
| 4 | 국가교육과정 성취기준 매칭 | 입력한 주제를 교육과정 성취기준 코드와 매칭해서 정합성 체크 |
| 5 | 자료 라이브러리 | 과거 생성·수정한 자료를 저장하고 검색·재사용 |
| 6 | 자유 게시판 | 수업내용 외 잡담 등 자유 주제로 정보 교류하는 오픈 커뮤니티. 강사·학교 교사 간 유대 형성 및 협업(7번 기능과 연결) 통로 역할. 수익모델은 광고 수익 |
| 7 | 실시간 협업 편집 | 여러 교사가 같은 강의안을 동시에 편집. CRDT 알고리즘을 직접 구현하지 않고 Yjs, Liveblocks 등 검증된 라이브러리를 통합해서 구현 |
| 8 | 논문/신규 자료 아카이브 + AI 요약 | 교육학 논문·최신 연구자료 자유 열람 + AI가 매주 최신 논문을 요약해서 트렌드 브리핑 제공 |

## AI 모델 선정

- **Vercel AI Gateway + Claude 계열 모델** 사용. Next.js·Vercel 배포 전제라 AI SDK로 provider/model 문자열만 지정해서 여러 모델을 하나의 게이트웨이로 관리(모델 교체·장애 대응·비용 추적 용이)
- 강의안·평가문항처럼 지시사항을 정확히 따라 구조화된 글을 써야 하는 작업은 Claude 계열이 강점
- **작업 난이도별 모델 등급 분리**로 비용 최적화:
  - 단순 작업(활동지 초안, 게시판 모더레이션 등) → 저렴하고 빠른 모델(예: Haiku급)
  - 복잡한 작업(강의안 초안, 성취기준 매칭, 평가문항 생성) → 더 강력한 모델(예: Sonnet급)

## 보안 고려사항

- **인증**: Clerk 사용 (Vercel 마켓플레이스 네이티브 통합 — 환경변수 자동 프로비저닝, 통합 결제, 로그인 UI 컴포넌트 제공). 구글·깃허브 등은 기본 지원, 카카오는 커스텀 OAuth로 추가. 카카오 연동 시 **비즈니스 앱 전환 여부**를 먼저 체크할 것(과거 이 부분을 몰라서 권한 문제 겪은 적 있음)
- **회원가입 방식**: 이메일+비밀번호 자체 가입은 넣지 않고 **소셜로그인 전용(구글+카카오 등 2개 이상)**으로 구성. 비밀번호 저장·해싱·재설정 로직 자체가 없어져 공격 표면이 줄고, 특정 제공자 장애에 대비해 2개 이상 소셜로그인을 병행
- **저작권**: AI가 생성한 자료라도 참고 출처(교육과정 성취기준 등)를 명시하고, 외부 저작물을 그대로 복제하지 않도록 주의
- **결제정보**: 카드번호 등은 우리 서버가 저장하지 않고 PG사(토스페이먼츠 등)가 처리
- **인프라**: HTTPS 기본 적용, API 키/시크릿은 환경변수 관리, 로그인 rate limiting
- **법적 문서**: 개인정보처리방침, 이용약관 (실서비스 지향이면 필수)
- **자유 게시판 모더레이션**: 욕설·스팸·불법 게시물(음란물, 도박·불법 광고 등)을 AI가 1차 자동 필터링해서 걸러내고, 애매한 건 신고 접수 후 최종 판단은 운영자가 수행
