# 부트캠프 팀 프로젝트 타겟 조사 보고서

- 작성일: 2026-07-27
- 조사 대상: ① 50~60대/은퇴 실버, ② 바이브코더, ③ 강사 (3개 모두)
- 규칙(AGENTS.md 준수): 모든 주장에 출처 URL 명시. 확인 못 한 수치·서비스는 **"미검증"** 표기. 각 타겟 원자료는 웹 검색 + 원문 WebFetch로 수집.

> **표기 규칙**: `[확정]` = 원문 페이지를 직접 열어 확인 / `[스니펫]` = 검색 결과 요약에만 근거, 원문 미열람 / **미검증** = 1차 출처 확인 실패. 발표 자료에 쓸 땐 이 등급을 그대로 유지할 것.

---

## 0. 3줄 요약 (결론 먼저)

1. **근거의 강도**만 보면 세 타겟 모두 pain point는 실재하며 공식 통계·언론·사건 사례로 뒷받침된다.
2. 그러나 **"부트캠프 4주 팀 프로젝트"라는 제약**(데이터 확보 용이성 × 경쟁 공백 × 4주 내 완성 가능성 × 법적 리스크 관리 가능성)을 곱하면 순위가 갈린다.
3. 이 기준에서 **강사(개인강사·과외·온라인 크리에이터용 "강의 영상 자산화 + 상담 리포트")를 1순위로 추천**한다. 바이브코더는 pain·데이터는 최상이지만 **경쟁이 이미 레드오션**, 실버는 **가장 강력한 pain(보이스피싱)이 법적·윤리적 리스크가 커서** 4주 MVP로 방어하기 어렵다. (상세 근거는 §4)

**2) 핵심 AI 기능**
- **Deployed-URL Authorization Prober**(배포 URL+anon key로 실제 익명요청 순회, 인증 없이 읽/쓰기 되는 데이터 증거 리포트) → *SAST는 코드 실행 안 해 "RLS 존재하나 오설정"을 못 잡음.* **단 Autonoma가 유사 포지셔닝.**
- **Plain-Language Risk Translator**(CWE 대신 "고객 이메일 3,200건 지금 다운로드 가능" 피해 서술 + 수정 PR) → *Snyk/Semgrep 리포트는 개발자 어휘라 비개발자에 무용.* **단 Sherlock Forensics가 유사.**
- **Ship Check 프리플라이트**(배포 전 훅: 실키 검증 + prod/dev 분리 + 백업 존재 + 요금 상한 체크) → *gitleaks는 키 문자열만 보고 살아있는지·과금한도·prod연결은 모름. Replit·Leo 사건은 코드결함이 아닌 운영설정 결함이라 SAST 대상 자체가 아님.* **경쟁 목록에서 유일한 빈자리.**

**3) 데이터 소스 (실존 확인 — 가장 견고)**
- [확정] OSV.dev API — 무료·키 불필요 — https://google.github.io/osv.dev/api/

- ❌ NVD API 미검증

**4) 경쟁/차별화 — ★포화도 높음(경고)**
- 바이브코더 특화 보안 스캐너가 **최소 8개** 이미 존재(VibeCheck, Aikido, VibeChecker, ChakraView, Lovable 2.0 내장 등) + 인접 Fencer/Sherlock/Autonoma/Corgea. — [DEV.to 비교글](https://dev.to/solobillions/i-tested-every-vibe-coding-security-scanner-2026-heres-what-actually-works-p9k)

**5) 리스크**
- 미탐 시 "false sense of security" 책임(SAST 47~80% 미탐 — arxiv 스니펫), 오탐 과다(50~80%)를 비개발자가 못 거름 → 신뢰 붕괴.

| **AI 기능의 "필수성"** | 강함(공식 DB 연동 필수) | 강함(런타임/운영설정은 SAST로 불가) | 강함(영상·학생 데이터 파이프라인 필수) |
| **데이터 소스 견고성** | 높음([확정] 경찰청·KOSIS) | **최상**([확정] OSV·Semgrep·GitHub·npm) | 높음([확정] Whisper·NCIC·학원데이터) |
| **경쟁 공백** | 중(교육은 정부 무료, 사기탐지는 공백) | **낮음(레드오션, 스캐너 8+)** | **중상**(인접자 있으나 세그먼트 빈틈) |
| **4주 MVP 적합성** | 중(STT·연동·시니어 UX 부담) | 중상(단, 차별화 지점이 좁음) | **높음**(영상 업로드→전사→색인→뷰어, 명확) |
| **법적/윤리 리스크** | **높음**(사기 오탐 책임, 민감정보) | 중상(미탐 책임, 코드 수집) | 중(미성년 동의, 채점 오류→사람 확인으로 완화) |
| **팀 자체 이해도(도그푸딩)** | 낮음 | **최상**(팀이 곧 사용자) | 중(강의 경험 있으면 상승) |

> 4주 MVP 규모는 세 타겟 모두 "평범한 개발자 3~4주"에 부합하도록 아래 §3에 스코프를 좁혀 제시. 스코프 판정은 **불확실**(팀 실력 편차)하며, 특히 실버의 "카메라 실시간 안내"는 4주 초과 위험.

## 3. 타겟별 권장 4주 MVP 스코프 (3~4주 규모로 조정)

- **A. 실버 — 보이스피싱 판별기**: 문자/통화 텍스트 붙여넣기 → 경찰청 사기유형 데이터 + 규칙/LLM 하이브리드 판정 → 위험도 + 신고 안내. (카메라 실시간 안내는 4주 **초과**로 제외 권장.) 1주 데이터 파이프라인·2주 판정 로직·3주 시니어 UX·4주 검증.
- **B. 바이브코더 — Ship Check 프리플라이트 CLI/훅**: GitHub 리포 연결 → 실키 검증(TruffleHog식) + prod/dev DB 분리 여부 + 백업/요금상한 설정 체크 → 통과/차단 리포트. (배포 URL 활성 스캔은 법적 리스크로 MVP 제외 권장.)
- **C. 강사 — 강의 영상 자산화 툴**: 영상 업로드 → Whisper 전사 → 챕터/자막/요약/퀴즈 생성 → 타임스탬프 색인 뷰어 + "질문→영상 구간" 검색. 1주 업로드·전사, 2주 색인·요약, 3주 뷰어/검색, 4주 퀴즈·다듬기.

## 4. 결론 및 추천 — **1순위: 강사(C)**

**추천: 개인강사·과외·온라인 크리에이터용 "강의 영상 자산화 + 상담 리포트" (타겟 C)**

근거:
1. **경쟁 공백 × 데이터 견고성의 균형이 가장 좋다.** 바이브코더는 pain·데이터가 최상이지만 특화 보안 스캐너가 **이미 8개 이상 존재하는 레드오션**([DEV.to 비교글](https://dev.to/solobillions/i-tested-every-vibe-coding-security-scanner-2026-heres-what-actually-works-p9k))이고, 팀이 낼 수 있는 차별화(A·B 아이디어)는 이미 Autonoma·Sherlock이 선점했다. 강사는 인접 경쟁자(매쓰플랫=수학 한정, 클라썸=대학/기업)가 **서로 다른 세그먼트**에 있어 개인강사용 영상 자산화에 **틈이 있다**.
2. **4주 MVP로 완성 형태가 가장 명확하다.** "영상 업로드 → Whisper 전사 → 색인·요약·퀴즈 → 뷰어" 파이프라인은 [확정]된 무료/저가 API(OpenAI STT, YouTube API)로 구성되며 단계가 뚜렷해 3~4주에 실질 산출물이 나온다.
3. **법적·윤리 리스크가 관리 가능한 수준이다.** AI 채점 오류 실사례가 있지만 "AI 초안 + 강사 최종 확인" 구조로 완화된다. 반면 실버 1순위 기능(보이스피싱)은 **오탐/미탐 시 금전 피해 책임**이 있고 그 법적 근거조차 미검증이라, 4주 프로젝트가 감당하기엔 위험이 크다.
4. **AI 기능이 "없으면 성립 안 되는" 조건을 충족한다.** 수 시간 영상의 전사·구간 인덱싱·수강생 배포는 범용 챗봇으로 대체 불가.

**단, 강사 선택 시 반드시 좁힐 것**: "모든 강사"가 아니라 **"영상 강의를 만드는 개인 강사/과외/온라인 크리에이터"** 한 세그먼트로 고정해야 매쓰플랫·클라썸과 정면충돌을 피한다.

**차순위 판단**:
- **바이브코더(2순위)**: pain·데이터·도그푸딩(팀이 곧 사용자)은 최고. **단 순수 스캐너를 피하고 "Ship Check(배포 전 운영설정 게이트)"라는 빈자리로 좁힐 때만** 승산. 이 각도라면 1순위와 재검토 가치 있음.
- **실버(3순위)**: pain은 사회적으로 가장 중대하나(보이스피싱 60대+ 30.6%), 최강 기능의 **법적 리스크 + 시니어 실사용 UX 검증 난이도**가 4주 프로젝트엔 부담.

> **의사결정 노트**: 팀이 "도그푸딩과 기술 도전"을 최우선으로 본다면 **바이브코더(Ship Check 각도)**, "완성도 높은 산출물과 낮은 리스크"를 최우선으로 본다면 **강사**다. 이 보고서는 후자 기준(부트캠프 산출물의 방어 가능성)에서 강사를 1순위로 둔다.
