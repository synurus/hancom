# 코드 리뷰: `260813_code_review_Q.js`

## 대상 코드

```js
const menu = ['김치찌개', '된장찌개', '비빔밥'];

const backup = menu;        // 개편 전 메뉴 백업

menu.push('냉면');           // 여름 신메뉴 추가
menu[0] = '김치찜';          // 김치찌개 → 김치찜으로 교체

console.log('개편 후 메뉴:', menu);
console.log('개편 전 백업:', backup);
```

## 실제 실행 결과

```
개편 후 메뉴: [ '김치찜', '된장찌개', '비빔밥', '냉면' ]
개편 전 백업: [ '김치찜', '된장찌개', '비빔밥', '냉면' ]
```

의도는 "백업은 개편 전 상태(`['김치찌개', '된장찌개', '비빔밥']`)로 남아 있어야 한다"였지만, `backup`도 `menu`와 완전히 동일하게 바뀌어 버립니다.

## Q1. 예상과 다르게 나온 출력은 어디인가?

21번째 줄 `console.log('개편 전 백업:', backup);`의 출력입니다. `['김치찌개', '된장찌개', '비빔밥']`이 나올 것으로 예상했겠지만, 실제로는 `menu`와 동일한 `['김치찜', '된장찌개', '비빔밥', '냉면']`이 출력됩니다.

## Q2. 왜 그런 결과가 나올까? 원인이 되는 코드는 어디인가?

원인은 15번째 줄입니다.

```js
const backup = menu;
```

`menu`는 배열(객체 타입)이고, 자바스크립트에서 객체·배열은 **값이 아니라 참조(메모리 주소)가 복사**됩니다. 즉 `backup`은 별도의 새 배열이 아니라, `menu`가 가리키는 것과 **동일한 배열을 가리키는 또 하나의 변수**일 뿐입니다.

`const`는 "변수(바인딩)를 재할당하지 못하게" 막을 뿐, 그 변수가 가리키는 객체의 내부 내용까지 얼려주지는(freeze) 않습니다. 따라서 이후

- `menu.push('냉면')` (17번째 줄)
- `menu[0] = '김치찜'` (18번째 줄)

처럼 배열 내부를 변경(mutate)하는 코드는 `menu`가 가리키는 원본 배열 자체를 수정하고, `backup`도 같은 배열을 가리키므로 `backup`을 통해 봐도 똑같이 바뀐 것처럼 보입니다.

정리하면, 배열/객체를 `=`로 대입하는 것은 "복사"가 아니라 "같은 실체를 가리키는 이름표를 하나 더 만드는 것"이라는 점을 놓친 것이 이 버그의 본질적 원인입니다.

## 수정 방안

"개편 전 상태를 진짜로 남기고 싶다"는 의도를 살리려면, 원본과 독립된 **새 배열(얕은 복사, shallow copy)**을 만들어야 합니다. 이 예제처럼 배열 요소가 문자열(원시값)뿐이라면 얕은 복사만으로 충분합니다.

```js
const menu = ['김치찌개', '된장찌개', '비빔밥'];

const backup = [...menu];   // 스프레드 문법으로 새 배열 생성
// 또는: const backup = menu.slice();
// 또는: const backup = Array.from(menu);

menu.push('냉면');
menu[0] = '김치찜';

console.log('개편 후 메뉴:', menu);
console.log('개편 전 백업:', backup);
```

이렇게 하면 `backup`은 `menu`와 별개의 메모리 공간을 가진 배열이 되어, `menu`를 아무리 수정해도 `backup`은 `['김치찌개', '된장찌개', '비빔밥']` 그대로 유지됩니다.

> 참고: 만약 배열 안에 객체가 들어있어 "깊은 복사(deep copy)"까지 필요한 경우라면 `[...menu]`나 `.slice()`로는 부족합니다(내부 객체는 여전히 참조 공유). 이런 경우 `structuredClone(menu)`(모던 환경) 또는 `JSON.parse(JSON.stringify(menu))` 같은 방법을 고려해야 합니다. 다만 이번 예제는 요소가 모두 문자열이므로 얕은 복사로 충분합니다.

## 핵심 학습 포인트

- 원시값(문자열, 숫자, boolean 등)은 대입 시 값 자체가 복사되지만, 객체·배열은 참조가 복사됩니다.
- `const`는 재할당만 막을 뿐, 객체·배열의 내부 변경(mutation)은 막지 못합니다.
- "복사본을 만들고 싶다"는 의도가 있다면 `=`가 아니라 `[...arr]`, `arr.slice()`, `Object.assign({}, obj)`, 스프레드(`{...obj}`) 등 명시적인 복사 방법을 사용해야 합니다.
