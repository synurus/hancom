# 회의록·채널 요약 자동화 시스템 — 와이어프레임

이 시스템은 화면(UI)이 있는 앱이 아니라 Discord 채팅으로 트리거되고 결과가 GitHub 파일로 쌓이는 구조라, 화면 목업 대신 **①전체 처리 흐름**과 **②실제 사용자가 마주치는 지점(채팅, 결과 파일)** 두 가지로 나눠서 정리함.

---

## 1. 전체 처리 흐름

```mermaid
sequenceDiagram
    participant U as 팀원 (Discord)
    participant B as Hermes2 봇
    participant S as meeting-minutes 스킬
    participant M as team-map.json
    participant G as GitHub (TeamB)

    U->>B: "@Hermes2 회의록 작성해줘 PT"
    B->>S: 스킬 실행 (채널ID + 주제태그)
    S->>B: fetch_messages(채널ID)
    B-->>S: 최근 대화 (핸들 + 사용자ID)
    S->>M: 사용자ID로 실명 조회
    M-->>S: 매핑 결과 (실명)
    S->>S: 본문 작성 (현재주제 / 논의내용 / 다음목표)
    Note over S: git 작업 안전장치 체크<br/>(변경사항 확인 → pull → add → commit → push)
    S->>G: 회의록 파일 push
    G-->>S: push 완료
    S->>B: reply (참여자 @태그 + GitHub 링크)
    B->>U: 완료 알림
```
